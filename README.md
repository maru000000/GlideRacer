# 🏎️💨 GLIDE RACER 🏁

: 추격의 질주, 레이싱의 자유


## 소개 🤓
군인과 경찰을 따돌리는 긴장감 넘치는 Car Chasing / Car Racing 게임이다.
기존 Car Chasing 스타일의 게임성과 함께 타임어택 모드를 추가하여 경쟁 요소를 강화했다.


## 게임 모드 🕹️
- Car Chasing
- Time Attack
- Training


## 실행 화면 📸

### Chasing

경찰차를 피해 오래도록 살아남는 것이 Chasing 모드의 목표다.
게임 시작과 동시에 경찰차가 스폰된다.
시간이 지날수록 phase가 늘어나고 그에 맞게 추격하는 경찰차의 수가 증가한다.

<img width="936" height="511" alt="스크린샷 2025-08-22 16 43 31" src="https://github.com/user-attachments/assets/a5500c62-9cf4-42b4-a471-93bbcab8b4c6" />
